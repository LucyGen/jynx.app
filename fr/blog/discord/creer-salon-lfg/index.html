Créer un salon LFG sur Discord : guide pas à pas

Pour créer un salon LFG sur Discord, il faut un salon dédié, quelques permissions bien réglées, des règles courtes, un modèle de message imposé et un rôle à mentionner par jeu. Voici les étapes dans l'ordre, sans jargon, avec les erreurs qui font mourir un salon en quelques semaines.

Étape 1 : choisir le bon type de salon

Deux options existent. Le **salon textuel** est le plus simple : tous les messages défilent dans un seul fil. Il convient à un petit serveur dédié à un jeu. Le **salon de type forum** donne à chaque demande son propre fil de discussion, avec des étiquettes (par exemple le jeu ou le mode) pour filtrer.

Une règle pratique : commencez par un salon textuel, et passez au forum le jour où deux conversations s'emmêlent dans le même salon. Dans les deux cas, nommez le salon sans ambiguïté (par exemple « recherche-de-joueurs » ou « lfg ») et, si votre serveur couvre plusieurs jeux, créez un salon par jeu plutôt qu'un fourre-tout.

Étape 2 : régler les permissions

Ouvrez les paramètres du salon (en général via l'icône de réglage à côté de son nom) puis l'onglet des permissions. L'objectif : que chacun puisse poster et répondre, mais pas dégrader le salon.
  • Tous les membres : voir le salon, écrire, lire l'historique, ajouter des réactions.
  • À restreindre : la mention de tout le serveur (@everyone et @here). Une demande de duo n'a aucune raison de notifier des centaines de personnes.
  • Modérateurs : gérer les messages, pour supprimer les annonces périmées.

Si vous créez un salon de lecture seule pour les règles, séparez-le du salon où l'on écrit. Les noms exacts des options varient selon la version de l'application : en cas de doute, consultez l'aide officielle de Discord.

Étape 3 : rédiger des règles courtes

Des règles trop longues ne sont pas lues. Cinq lignes suffisent :
  1. Un seul post actif par personne.
  2. Utiliser le modèle de message (étape 4).
  3. Supprimer ou modifier son post dès que le groupe est complet.
  4. Pas de boosting, d'achat de compte ni de publicité.
  5. Respect des autres joueurs, sinon sanction.

Épinglez-les en haut du salon. Pour ajouter un délai entre deux messages, activez le mode lent dans les paramètres du salon : quelques minutes empêchent de republier la même demande en boucle.

Étape 4 : imposer un format de message

Une annonce n'est utile que si elle répond aux questions avant qu'on les pose. Épinglez un modèle et demandez de le suivre :
Jeu : Valorant
Mode : classé
Rang déclaré : Or 2
Région / langue : EU Ouest, français
Recherche : 2 joueurs
Vocal : oui
Quand : ce soir 21h, environ 2 heures

La ligne « Quand » compte beaucoup : elle permet d'ignorer un post de la veille sans rien demander. Le rang étant déclaré par le joueur et non vérifié par Discord, précisez-le comme tel dans le modèle (« rang déclaré »), et conseillez de jouer une première partie avant de s'engager. Pour mieux choisir un rang à annoncer, consultez nos pages sur les rangs de Valorant ou de League of Legends.

Étape 5 : créer des rôles à mentionner

Créez un rôle par jeu (et par mode si le serveur est grand), puis laissez les membres se l'attribuer eux-mêmes via un menu de rôles ou un message à réactions. Une annonce peut alors mentionner « le rôle Valorant » et ne notifier que les personnes qui ont dit oui.

Rendez ces rôles mentionnables uniquement dans le salon LFG, et gardez les rôles de modération hors de portée des membres. Ce principe de ciblage limite les coupures de son du serveur, première cause de désabonnement des notifications.

Étape 6 (optionnelle) : ajouter un bot

Le LFG manuel fonctionne tant que le volume reste raisonnable. Un bot devient utile quand :
  • les annonces doivent disparaître seules une fois le groupe complet ou périmé ;
  • vous voulez un bouton pour rejoindre à la place du message privé ;
  • le ménage épuise vos modérateurs.

Choisissez un bot dont vous comprenez les permissions demandées, et ne lui accordez que celles dont il a besoin. Nous détaillons les options dans notre guide des bots LFG pour Discord.

Quand un salon LFG ne suffit plus

Un salon bien configuré règle le désordre, pas les limites du format. Dans un salon actif, les annonces descendent vite, le rang annoncé n'est pas vérifié et rien ne garantit que le joueur qui répond ait vos horaires. Si vous cherchez un partenaire régulier plutôt qu'un dépanneur, ou si votre serveur est trop petit pour que le salon vive, un salon LFG ne suffit plus.

C'est le cas pour lequel Jynx est pensé : filtres par rang, rôle, langue et région (le rang est déclaré par le joueur), compatibilité d'horaires, découverte en swipe, vocal natif et sessions planifiées dans une même application gratuite sur iOS, Android et web. Les deux se complètent : gardez Discord pour votre communauté et son vocal, et cherchez vos coéquipiers sur Jynx. Questions fréquentes

Comment faire un salon LFG sur Discord ?
Créez un salon textuel (ou un salon de type forum) dans votre serveur, nommez-le clairement, réglez ses permissions, épinglez un modèle de message et créez un rôle par jeu. Les intitulés exacts des menus peuvent changer : repérez-les dans les paramètres de votre serveur.
Faut-il un salon textuel ou un forum pour un LFG ?
Un salon textuel suffit pour un petit serveur centré sur un jeu. Un forum devient utile quand plusieurs conversations se mélangent ou quand le serveur couvre plusieurs jeux, car chaque demande a son propre fil.
Faut-il un bot pour un salon LFG ?
Non, ce n'est pas obligatoire. Un bot sert surtout à supprimer automatiquement les annonces périmées ou à proposer un bouton pour rejoindre, quand le ménage manuel devient trop lourd.
Pourquoi mon salon LFG reste-t-il vide ?
Les causes fréquentes sont l'absence de format, des posts jamais nettoyés qui donnent l'impression d'un salon mort, et des mentions mal ciblées. Un rôle par jeu et un ménage régulier règlent souvent le problème.
